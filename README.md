# TikTok TechJam 2026 — Track 5: Robust Detection of AI-Generated Images

Team project for [TikTok TechJam 2026](https://tiktoktechjam2026.devpost.com/), Track 5: **Robust Detection of AI-Generated Images Under Real-World Transformations** — detect AI-generated vs authentic images, staying accurate under JPEG compression, blur, resize, noise, color jitter, and cropping. Full brief: [docs/TRACK5_BRIEF.md](docs/TRACK5_BRIEF.md).

> **Status:** Setup phase. Key constraint: models must be **< 2B parameters**.
