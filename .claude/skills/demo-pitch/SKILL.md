# Demo & Pitch (TechJam submission)

Deliverables: written solution description (with tech stack), public repo README, public 3-min YouTube video.

## 3-minute video structure (strict)

- 0:00–0:25 — The problem, made concrete with one vivid example. No team intro fluff.
- 0:25–0:50 — Our solution in one sentence + what's novel about the approach.
- 0:50–2:20 — **Live demo of the real product**, narrated as a user story. Show real inputs → real outputs. One flawless happy path > three shaky features.
- 2:20–2:50 — How it works (one architecture slide, ≤ 15 seconds on it) + impact/feasibility claim with a number if possible.
- 2:50–3:00 — Recap + team/track tag.

Rules: script it word-for-word, record screen at 1080p+, big fonts/zoomed UI, cut dead air aggressively. Upload as **public** (not unlisted — check rules) and test the link in an incognito window.

## Written description

Structure: Problem → Solution → How it works (tech stack, APIs, models) → What's novel → Impact & feasibility → Limitations & next steps. Mirror the judging criteria vocabulary. Honest limitations earn credibility; include 2–3.

## README checklist

- [ ] One-paragraph pitch + hero screenshot/GIF at the top
- [ ] Setup that a judge can run in < 5 minutes (or a hosted demo link)
- [ ] Architecture diagram
- [ ] Tech stack + APIs/models used (required by rules)
- [ ] Team members and track
